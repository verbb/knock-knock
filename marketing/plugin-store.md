Knock Knock places a simple shared-password gate in front of a Craft site. Protect a staging site, private preview, or work in progress without building a complete member system.

Visitors enter one project password before accessing protected pages. Successful access is remembered for the configured period, making the gate useful for client review without creating and maintaining individual Craft accounts.

## Features

- Protect the public site with one credential that is easy to rotate.
- Avoid asking approved visitors for the password on every page.
- Leave selected endpoints available when integrations or public pages need them.
- Allow trusted networks through without the password screen.
- Use project-owned templates or responses for the gate.
- Keep access behaviour explicit alongside the rest of the site configuration.
- Use environment variables for the password and enabled state across deployments.
