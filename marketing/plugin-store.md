Knock Knock places a simple shared-password gate in front of a Craft site. Protect a staging site, private preview, or work in progress without building a complete member system.

Visitors enter one project password before accessing protected pages. Successful access is remembered for the configured period, making the gate useful for client review without creating and maintaining individual Craft accounts.

## Features

- **Shared password:** Protect the public site with one credential that is easy to rotate.
- **Remembered access:** Avoid asking approved visitors for the password on every page.
- **Route exceptions:** Leave selected endpoints available when integrations or public pages need them.
- **IP bypass:** Allow trusted networks through without the password screen.
- **Custom presentation:** Use project-owned templates or responses for the gate.
- **Config-driven rules:** Keep access behaviour explicit alongside the rest of the site configuration.
- **Environment settings:** Use environment variables for the password and enabled state across deployments.
- **Practical access rules:** Choose the routes that remain available, bypass the gate for approved IP addresses, and customise the password form or response to fit the project. Signed-in control-panel work can remain separate from the public-site gate.
